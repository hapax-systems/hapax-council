## Vibe binding

User instruction loading must be enabled in the declared Vibe source set;
project instruction loading is trust-conditioned. The global file is
`$VIBE_HOME/AGENTS.md` (default `~/.vibe/AGENTS.md`).

For an estate lane, read `~/.cache/hapax/relay/onboarding-vbe.md`, use the
relay-protocol skill when available, and inspect the lane identified by
`HAPAX_AGENT_ROLE` in the existing relay/claim context. Apply its
protected-path and review-tier constraints. Lane identity and the active task
are runtime context, not repository `AGENTS.md` content. Do not regenerate or
overwrite repository instructions during launch. Resume must retain the
explicit owned native session state; a new process alone is not continuation.
