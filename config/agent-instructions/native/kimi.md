## Kimi binding

Use `$KIMI_CODE_HOME/AGENTS.md` (default `~/.kimi-code/AGENTS.md`); do not also
inject the common body through `~/.agents/AGENTS.md`. `SYSTEM.md` replaces the
native system prompt and is not this policy-distribution mechanism.

A claiming lane uses the admitted `hapax-kimi <role>` launch shape, with
identity, session marker and relay-retire behavior. Its configured hooks may
adapt tool payloads to the canonical hook chain; their existence does not
make the advisory task gate a hard boundary or authorize bypassing a refusal.
Native MCP bindings are in the declared Kimi configuration; do not assume
every host has the same servers or endpoints.

For Gate0A evidence, retain exact source/host receipt bindings and independent
review separation. Rehash the durable authorized artifact pair before use.
Use whole-second UTC `YYYY-MM-DDTHH:MM:SSZ`; floor fractional seconds. A silent
CLI exit is not a diagnosis: expose the typed validation error with the pinned
renderer without invoking its apply path. Do not reconstruct remote evidence
locally and call it a remote observation.

Follow `lanebus/PROTOCOL.md` for create-only inbox drops and read acknowledgements.
When a summary is requested, preserve request and delivery timestamps in the
existing relay and continue from the delivered anchor.
