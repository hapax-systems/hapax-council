# Constitutional Bill of Materials

The kernel does not ship a values profile as an undisclosed default. Adopters
receive a disclosed procedural substrate: deny-wins, fail-closed unknowns,
evidence burdens, visibility, weights, contestability, recovery, and an
amendment path are enumerated in the generated [Constitutional Bill of
Materials](../constitutional-bill-of-materials.json).

The estate's own values are available only as the explicitly labelled
`hapax-estate-reference` profile. It is an example that can be swapped, not a
quiet product default.
